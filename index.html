Entenda um projeto do GitHub sem precisar entender GitHub.

Cole um repositório público. O NewbieHub explica o que ele faz, para quem serve, como começar e quais sinais merecem atenção — em linguagem para quem está começando do zero.

Nunca cole seed, chave privada, passphrase, senha ou token. O NewbieHub só precisa do link público do repositório.
